## 2. Разбор присланных каруселей

### A. @ilia.paliy — «Instagram × Claude» (9 слайдов)
- **Механика:** CTA «Пиши «ВИДЕО» в комментариях». Итог: 208 комментариев при 109 лайках. Комментарии в 2 раза обгоняют лайки, и алгоритм это продвигает.
- **Дизайн:** тёмный фон с зерном, белый гротеск + оранжевый курсив с засечками, «стеклянные» 3D-иконки, служебная строка сверху (`INSTAGRAM × CLAUDE · 07/09`) и снизу (тема слайда + точки прогресса).
- **Смысл слайда 7:** подключение Claude к Instagram идёт через официальный доступ Meta. У нас это уже сделано через Metricool: он работает по официальному API Meta.
- **Что берём:** кодовое слово в комментариях → автоответ в Direct с лид-магнитом. Нумерация «07/09» на каждом слайде.

### B. @bezikovkirilll — «10 промптов для Claude: пассивный доход» (10 слайдов)
- **Механика:** CTA «Сохраните, чтобы не потерять» + закладка. Итог: 241 репост и 198 лайков. Полезный контент «на потом» собирает сохранения и репосты.
- **Формула слайда:** заголовок капсом (2 строки белым + 1 строка оранжевым) → подзаголовок-выгода → рамка «ПРОМПТ ДЛЯ CLAUDE» → CTA.
- **Ошибки, которые не стоит повторять:**
  - Слайд 7 «Добавляйте источники дохода в правильном порядке» дословно повторяет подзаголовок и промпт слайда 6 (маркетинг). Это copy-paste-баг.
  - Номер слайда дублируется: «02/10» в макете и «2/10» поверх. Выглядит грязно.
- **Что берём:** формат «1 слайд = 1 готовый промпт». Такой контент сохраняют чаще всего.

### Как применить к фитнес-блогу
- **Формат B («промпт в рамке») напрямую для твоей ниши:** карусель «7 промптов для Claude, чтобы самому собрать сушку». Слайды: расчёт КБЖУ, милплан, замены продуктов, тренировка под дефицит, разбор плато, сон, самотест осанки по фото. Аудитория сохранит, а последний слайд ведёт на онлайн-ведение: «промпт даст шаблон, тренер подстроит под тебя».
- **Механика A (слово в комментариях):** «Пиши СУШКА — пришлю главу гайда». Это лид-магнит из уже готового документа и заодно рост комментариев.
- **Кейс 05.10 оформить заново** по формуле B: заголовок «Болит колено? Дело может быть в ягодице», 1 мысль на слайд, призыв сохранить. Сейчас вся польза спрятана в длинной подписи.

### Промпты из карусели B (оригинал, для справки)
1. **Полный план** — роль предпринимателя + финансового преподавателя + системного архитектора. Анализ навыков, бюджета, риска и целей. Отделять проверенное от предположений.
2. **Найти источник дохода** — сравнить модели (цифровые продукты, партнёрки, софт, контент, обучение, подписки) по сложности, трудозатратам, масштабу, риску.
3. **Продукт, который продаётся сам** — спрос → проверка идеи → продукт → цена → запуск → маркетинг → портфель.
4. **Автоматизировать рутину** — где ИИ берёт на себя исследования, контент, поддержку, аналитику без потери качества.
5. **Клиенты без погони** — контент, SEO, email, соцсети, партнёрства, рефералы, сообщества.
6. **(дубль слайда 5 в оригинале)**. Правильная версия: «В каком порядке добавлять источники дохода, с учётом зависимостей и денежного потока».
7. **Проверять, что работает** — дашборд: трафик, конверсия, CAC, LTV, удержание, MRR, маржа + еженедельный разбор.
8. **Финансовая устойчивость** — реинвест, диверсификация, кэшфлоу, риски, подушка, сценарии.

## 3. Инструменты: как это собирается в систему

```
Идея/промпт ──► Claude (текст карусели)
                  │
                  ▼
           Orshot (шаблон карусели → рендер 1080×1350, 7–10 слайдов)
                  │
                  ▼
           Metricool (планирование в лучшее время + аналитика)
                  │
                  ▼
           Claude читает метрики → правит контент-план (Claude Docs / этот репо)
```

### Коннекторы

**Уже подключены, используем сразу:**
- **Metricool**: планирование каруселей, `getBestTimeToPostByNetwork`, еженедельная аналитика (охват, сохранения, репосты, прирост).
- **Orshot**: делаем 2 фирменных шаблона карусели (стиль A и стиль B), дальше рендерим пачкой через `batch_render`.
- **Google Drive**: папка с исходниками, фото, готовыми рендерами.
- **Claude Docs**: контент-план и сценарии, которые можно комментировать.

**Предлагаю подключить** (claude.ai → Settings → Connectors):
- **Canva**: если удобнее править дизайн руками; Claude умеет автозаполнять шаблоны.
- **Notion**: база идей и контент-календарь, если Docs покажется мало.
- **Moda / Motion Creative Analytics**: когда дойдём до рекламы Meta (креативы, библиотека конкурентов).
- **Stripe**: когда появится платный продукт (гайд, консультация).
- **ManyChat / автоответчик Direct**: в каталоге коннекторов Claude его нет. Для механики «пиши слово в комментариях» его нужно настроить в самом ManyChat. Claude напишет сценарии и тексты.

### Скилы (повторяемые сценарии для Claude)
1. **`carousel-writer`**: хук из контент-банка → 7–10 слайдов в твоём голосе (по образцу введения гайда) по формуле «хук → проблема → 1 мысль на слайд → CTA». Проверяет повторы между слайдами и фильтр «без схем и доз фармы».
2. **`orshot-carousel-render`**: текст слайдов → рендер в Orshot по фирменному шаблону → ссылки на картинки.
3. **`metricool-weekly-report`**: каждый понедельник берёт метрики за неделю, выбирает топ-3 поста по сохранениям и репостам и предлагает темы на следующую неделю.
4. **`comment-keyword-funnel`**: кодовое слово + текст лид-магнита + сценарий автоответа.
5. **`competitor-teardown`**: разбор чужой карусели (как этот документ) по скриншотам.
6. **`client-case`**: план клиента из Drive (питание/сплит) + замеры → анонимный кейс «до/после» для карусели и главы «Кейсы».
7. **`guide-chapter`**: пишет следующую главу гайда в Claude Docs и сразу нарезает из неё 3 единицы контента.

Встроенные скилы, которые уже есть: `dataviz` (графики по метрикам), `pptx`/`pdf` (лид-магнит-гайд), `skill-creator` (чтобы оформить скилы выше).
