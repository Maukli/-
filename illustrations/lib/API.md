# figure.js: рисование упражнений кодом

```js
const { drawExercise } = require('./figure');
const svg = drawExercise(spec); // строка SVG 900 на 650
```

CLI: `node build.js spec.json [out.svg] [--no-png]`. Пишет SVG и сразу PNG рядом (через render.js).
Галерея проверки: `test/run_all.sh`.

## spec

| Поле | Что это |
|---|---|
| `title`, `hint` | Заголовок 28px и подсказка 18px (до 2 строк, перенос автоматически) |
| `view` | `side` (профиль, по умолчанию), `front` (фас), `back` (спина) |
| `floor` | y пола. Рисуется светлая линия, если нет `mat` или `floor` в снарядах |
| `scale` | Масштаб фигуры, 1 = рост 440 px |
| `pose` | Поза, см. ниже |
| `ghost` | Вторая поза (старт или конец движения): голубой пунктирный контур, чтобы не путать с дальними конечностями (они серые сплошные). `{ "pose": {...}, "opacity": 0.9 }`. Поля сливаются с `pose`. Направление показываем стрелкой в `arrows` |
| `equipment` | Список снарядов |
| `work`, `stretch` | Мышцы: работающие (#E53935, 0.8) и растягиваемые (#FB8C00, 0.6). Строка или объект |
| `arrows` | Стрелки движения (#1E88E5) |
| `notes` | Свободные подписи `{ "text", "at", "size", "color", "anchor" }` |
| `legend` | Легенда цветов. По умолчанию есть, только если есть оба типа мышц |

### pose

Все углы в градусах. Фигура в профиль смотрит вправо, если `facing` не `left`.

| Поле | Что это |
|---|---|
| `pelvis` | `[x, y]` тазобедренного сустава на холсте. `[x, "floor"]`: y подбирается так, чтобы нижняя точка тела легла на `floor` |
| `rotate` | Поворот всего тела по часовой. Лёжа на спине головой влево: `-90`. Лёжа на спине головой вправо: `facing: "left"`, `rotate: 90` |
| `facing` | `right` или `left` |
| `near` | Какая сторона ближе к зрителю в профиль: `l` (по умолчанию) или `r`. Дальняя рисуется светлее |
| `trunk` | Наклон таза и корпуса вперёд от вертикали (присед 40, тяга в наклоне 70). В фас: наклон вбок |
| `pelvisTilt` | Наклон таза: + передний, - задний |
| `lumbar`, `thoracic` | Сгибание (+) и разгибание (-) поясницы и грудного отдела: круглая или прогнутая спина |
| `neck`, `head` | Сгибание (+) и разгибание (-) шеи и головы |
| `l`, `r`, `both` | Суставы сторон. `both` применяется к обеим, `l` и `r` переопределяют |
| `farShift` | Сдвиг дальних конечностей `[dx, dy]` для читаемости |
| `order` | Порядок слоёв, если нужен другой: `["farLeg","farArm","torso","nearArm"]` (фас: `["body","armR","armL"]`) |

Суставы стороны (профиль):
- `shoulder`: сгибание плеча (0 рука вдоль тела, 90 вперёд, 180 вверх, минус назад)
- `elbow`: сгибание локтя, `wrist`: сгибание кисти
- `hip`: сгибание бедра относительно корпуса (0 стоя, 90 бедро вперёд), минус разгибание
- `knee`: сгибание колена, `ankle`: тыльное сгибание (+ носок к голени, - носок от себя)
- `hand`: `fist` или `open` (по умолчанию кулак, если есть `gripAt`)
- `lengths`: `{ "upper": 0.8 }` укорочение сегмента для ракурса

В фас и со спины: `shoulder` и `hip` это отведение, `elbow` и `knee` сгибание в плоскости рисунка.

Обратная кинематика (вместо углов): `handAt` (запястье), `gripAt` (центр кулака), `footAt` (голеностоп). Цель: `[x, y]`, имя точки торса или плеча (`upperback`, `shoulder_near`, `chest`, `back`, `belly`, `hip` ...) или `{ "at": "upperback", "dx": 4, "dy": -2 }`. `bend: -1` выбирает второе решение (локоть или колено в другую сторону).

### Точки тела (для стрелок, снарядов, подписей)

`pelvis, hip, head, nose, chin, neck, chest, sternum, back, upperback, lowback, belly, butt, sacrum`, и для сторон с суффиксом `_l`, `_r`, `_near`, `_far`: `shoulder, elbow, wrist, hand, fingers, knee, ankle, heel, toe, ball, shin, thigh, kneefront`. Везде можно `{ "at": "knee_near", "dx": 20, "dy": -10 }`. Высота голеностопа над полом при плоской стопе: 23 px.

### Мышцы

`deltoid, pecs, lats, trap_upper, trap_middle, trap_lower, traps, rhomboids, serratus, biceps, triceps, forearm, rectus_abdominis, obliques, erectors, glute_max, glute_med, glute_min, tfl, iliopsoas, piriformis, quads, rectus_femoris, adductors, hamstrings, gastrocnemius, soleus, tibialis_anterior, neck_flexors, foot`.

Объект мышцы: `{ "name": "quads", "side": "near"|"far"|"both"|"l"|"r", "label": "Свой текст" | false, "labelAt": [x,y], "labelSide": "left"|"right"|"top"|"bottom", "anchor": точка }`. Подпись по умолчанию русская, выноска ставится к видимой части мышцы и уходит к свободному краю. Глубокие мышцы (подвздошно-поясничная, малая ягодичная, грушевидная, ромбовидные, приводящие в профиль) светлее и с пунктирным контуром. Мышца клипуется по своим сегментам и по контуру своего слоя. Если от мышцы видно меньше 90 px2 (например, зубчатая целиком под рукой), она дополнительно рисуется пунктиром поверх руки.

Раскладка подписей: якоря разных мышц не ближе 18 px; в фас и со спины якорь парной мышцы берётся на той половине, куда уходит подпись. Подпись ставится в колонку сбоку, сверху, снизу или (в профиль) на свободное место рядом. Выноска не идёт по чужим частям тела дольше 26 px (в фас и со спины 40 px, можно перейти через руку), не пересекает снаряды, чужие выноски и подписи. Порядок подписей в колонке совпадает с порядком якорей.

### Снаряды

`{ "type": ..., ... }`, точки как выше. Слой: `layer: "back"|"front"`, по умолчанию снаряды за телом, а гантели и гири между телом и ближней рукой.

| type | Поля |
|---|---|
| `mat`, `floor` | `x, y, w` |
| `bench` | `x, y` (верх), `w` |
| `incline_bench` | `hinge`, `angle`, `len`, `seat`, `back: "left"|"right"` |
| `box`, `wall` | `x, y, w, h` / `x, top, side` |
| `barbell` | `at`, `r` (в профиль блин, в фас гриф) |
| `dumbbell`, `kettlebell`, `plate`, `ball`, `foam_roller` | `at`, `r` |
| `stick`, `band` | `from`, `to` |
| `cable_low`, `cable_high` | `x`, `to` (точка рукояти), `top`, `handle: false`. Без `to` трос висит вниз от верхнего блока (`hang`, px) или лежит к полу от нижнего, на конце D-рукоять |
| `pullup_bar`, `dip_bars` | `at`, `w` |
| `machine_leg_ext` | `seat`, `axis`, `pad`, `backX` |
| `machine_adductor` | `at`, `pads` |
| `roman_chair` | `hip`, `foot` |
| `rect`, `circle`, `line`, `poly` | Свои формы цветом снарядов |

### Стрелки

- Прямая: `{ "from": P, "to": P, "label": "вверх", "bend": 0.3, "both": true, "dash": true, "labelSide": "left"|"right"|"below" }`
- Дуга: `{ "arc": { "center": P, "r": 150, "start": -80, "end": -25 }, "label": "..." }`. Углы экранные: 0 вправо, 90 вниз, -90 вверх.

## Примеры

Присед со штангой (профиль, авто-пол, хват через обратную кинематику; укороченные плечо и предплечье дают ракурс, локоть уходит назад и вниз):

```json
{
  "title": "Присед со штангой", "hint": "Гриф на трапециях, спина ровная",
  "floor": 590,
  "pose": { "pelvis": [420, 420], "trunk": 44, "neck": -14,
    "both": { "hip": 118, "knee": 103, "ankle": 25, "gripAt": { "at": "upperback", "dx": -3, "dy": -1 }, "bend": -1,
      "wrist": -10, "lengths": { "upper": 0.86, "fore": 0.72 } } },
  "equipment": [ { "type": "barbell", "at": { "at": "upperback", "dx": -4, "dy": -2 } } ],
  "work": ["quads", "glute_max", "erectors"],
  "arrows": [ { "from": [640, 470], "to": [640, 330], "label": "вверх" } ]
}
```

Подъём ног лёжа (поворот тела, дуга, растяжение; руки вдоль тела, чтобы не закрывать голову):

```json
{
  "title": "Подъём ног лёжа", "floor": 580,
  "pose": { "pelvis": [520, 534], "rotate": -90,
    "both": { "hip": 90, "ankle": -40, "shoulder": -7, "elbow": 4, "hand": "open" } },
  "equipment": [ { "type": "mat", "x": 160, "y": 568, "w": 600 } ],
  "work": ["rectus_abdominis", "iliopsoas"], "stretch": ["hamstrings"],
  "arrows": [ { "arc": { "center": [520, 534], "r": 175, "start": -80, "end": -25 }, "label": "медленно вниз" } ]
}
```

Вид со спины:

```json
{
  "title": "Тяга к поясу", "view": "back", "floor": 600,
  "pose": { "pelvis": [450, "floor"], "both": { "shoulder": 25, "elbow": 20, "hip": 4, "knee": 3 } },
  "work": ["traps", "lats", "rhomboids"]
}
```
