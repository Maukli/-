# Скилы проекта

Скилы в этой папке Claude Code подключает автоматически в каждой сессии с этим репозиторием.

## Из ECC (github.com/affaan-m/ECC, коммит 90606c8, лицензия MIT — см. LICENSE-ECC)

Скопированы без изменений после ручной проверки: только текстовые инструкции, без скриптов, без сетевых вызовов, без скрытых символов.

| Скил | Зачем нам |
|---|---|
| `brand-voice` | собрать профиль голоса Микаела из реальных текстов (введение гайда, подписи к постам) и писать весь контент в нём |
| `content-engine` | нарезка одного источника (глава гайда, кейс клиента) на рилсы, карусели и подписи; запрет на шаблонный ИИ-текст |
| `marketing-campaign` | запуск онлайн-ведения: позиционирование → гайд как лид-магнит → посты → сторис → контент-календарь |
| `market-research` | разбор конкурентов-фитнес-блогеров и спроса с источниками |

Примечания по использованию:
- Примеры в скилах заточены под X и LinkedIn — для нас платформа Instagram (рилсы, карусели, сторис).
- В `brand-voice` есть «Affaan / ECC defaults» — для нас не применяются, голос берём из твоих текстов.
- `content-engine` запрещает «engagement bait» без явного согласия: механика «пиши СУШКА в комментариях» одобрена тобой, её использовать можно.

## Что не взяли и почему
- `social-publisher` — требует сторонний сервис SocialClaw, его API-ключ и глобальную установку npm-пакета. Публикацию уже делает Metricool.
- `seo` — про SEO сайтов (robots.txt, Core Web Vitals); сайта у нас нет.
- Видео-скилы (`video-editing`, `remotion-video-creation`) — нужны ffmpeg/Node-проекты, для рилсов с телефона избыточно.
- Остальные ~300 скилов, 71 агент и хуки ECC — про программирование; хуки запускают скрипты на каждое действие.
